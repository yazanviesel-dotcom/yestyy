# موقع عربي جاهز للنشر عبر GitHub Pages

هذا المشروع عبارة عن موقع إلكتروني بسيط وحديث (Landing Page) باللغة العربية، جاهز للنشر مباشرة عبر GitHub.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح:

`http://localhost:8000`

## النشر عبر GitHub Pages

1. ارفع المشروع إلى مستودع GitHub.
2. من إعدادات المستودع → **Pages** اختر النشر عبر **GitHub Actions**.
3. الـ Workflow الحالي يدعم النشر تلقائيًا عند `push` على فروع `main` أو `master` أو `work`.
4. إذا كان اسم فرعك مختلفًا (مثل `work`) عدّل ملف:
   `.github/workflows/deploy.yml`
   وأضف اسم الفرع داخل `on.push.branches`.

## لماذا ممكن "ما يشتغل"؟ (حل سريع)

- **الفرع غير مدعوم في الـ Workflow**: إذا كنت تعمل على فرع غير `main`/`master`/`work` فلن يبدأ النشر تلقائيًا.
- **تشاهد شاشة بيضاء في المعاينة**: غالبًا هذا لأن رابط المعاينة لا يشير لنسخة منشورة بعد. افتح رابط GitHub Pages النهائي بعد نجاح Action `deploy` من تبويب **Actions**.
- **GitHub Pages غير مفعّل**: تأكد من اختيار **GitHub Actions** داخل إعدادات Pages.
- **أول نشر يحتاج دقائق**: أحيانًا الرابط يظهر بعد 1-5 دقائق من نجاح الـ Action.
- **الـ Actions فشلت**: افتح تبويب **Actions** وتحقق من خطوات job `deploy`.

## التخصيص السريع

- عدل النصوص في `index.html`.
- عدل الألوان والخطوط في `styles.css`.
- عدل سلوك النموذج في `script.js`.
